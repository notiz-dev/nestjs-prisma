This guide covers how to install Prisma and integrate it into your NestJS application. You have two main options for integration: using the `nestjs-prisma` library or copying `PrismaService` into your project.

## Prerequisites

First, setup [Prisma](https://www.prisma.io/docs/getting-started) in your project and select an [adapter](https://www.prisma.io/docs/getting-started#-already-have-your-own-database) for your database.

<Steps>

1.  Install the required Prisma dependencies:

    <Tabs syncKey="pkg">
    <TabItem label="npm">

    ```bash
    npm install prisma dotenv --save-dev
    npm install @prisma/client 
    ```

    </TabItem>
    <TabItem label="pnpm">

    ```bash
    pnpm add -D prisma dotenv
    pnpm add @prisma/client 
    ```

    </TabItem>
    <TabItem label="yarn">

    ```bash
    yarn add -D prisma dotenv
    yarn add @prisma/client 
    ```

    </TabItem>
    </Tabs>

2.  Prisma v7+ requires a [database driver](https://www.prisma.io/docs/orm/overview/databases/database-drivers) to be installed for your chosen database.

    :::note
    The install commands below cover the drivers for PostgreSQL, MySQL, and SQLite. For other supported databases, please refer to the [Prisma documentation](https://www.prisma.io/docs/getting-started#-already-have-your-own-database).
    :::

    <FileTree>

    - prisma

    - .env add to .gitignore
    - prisma.config.ts Prisma configuration

    :::note
    You may need to set `moduleFormat = "cjs"` in your `schema.prisma` file for the `client` generator.
    :::

4.  Configure the `DATABASE_URL` in `.env` to match your database.

5.  Add a data model in `prisma/schema.prisma`. For example, a `User` model:

    ```prisma
    model User {
      id    String  @id @default(cuid())
      email String  @unique
      name  String?
    }
    ```

6.  Create and apply the first Prisma migration and generate the Prisma Client.

    <Tabs syncKey="pkg">
    <TabItem label="npm">

    ```bash
    npx prisma migrate dev --name init
    npx prisma generate
    ```

    </TabItem>
    <TabItem label="pnpm">

    ```bash
    pnpm prisma migrate dev --name init
    pnpm prisma generate
    ```

    </TabItem>
    <TabItem label="yarn">

    ```bash
    yarn prisma migrate dev --name init
    yarn prisma generate
    ```

    </TabItem>
    </Tabs>

7.  Add `import 'dotenv/config';` to your `src/main.ts` file to ensure `DATABASE_URL` (environment variables `process.env`) is loaded.

    ```typescript
    // src/main.ts
    import 'dotenv/config';

    import { NestFactory } from '@nestjs/core';
    import { AppModule } from './app.module';

    async function bootstrap() {
      const app = await NestFactory.create(AppModule);
      await app.listen(process.env.PORT ?? 3000);
    }
    bootstrap();
    ```

</Steps>

## Install the Package

The `nestjs-prisma` library simplifies the usage of Prisma within NestJS applications.

:::note
This documentation is for the current dev release. Visit [nestjs-prisma.dev](https://nestjs-prisma.dev) for the previous stable version.
:::

<Steps>

1.  **Install dependencies**

    Install `nestjs-prisma`:

    <Tabs syncKey="pkg">
    <TabItem label="npm">

    ```bash
    npm install nestjs-prisma@0.28.0-dev.0
    ```

    </TabItem>
    <TabItem label="pnpm">

    ```bash
    pnpm add nestjs-prisma@0.28.0-dev.0
    ```

    </TabItem>
    <TabItem label="yarn">

    ```bash
    yarn add nestjs-prisma@0.28.0-dev.0
    ```

    </TabItem>
    </Tabs>

2.  **Create Prisma Client Instance**

    Create a `prisma-client.ts` file and create an instance of the Prisma Client.

    ```typescript
    // src/prisma-client.ts
    import { PrismaBetterSqlite3 } from '@prisma/adapter-better-sqlite3';
    import { Prisma, PrismaClient } from './generated/prisma/client';

    const adapter = new PrismaBetterSqlite3({ url: process.env.DATABASE_URL! });
    export const prismaClient = new PrismaClient({ adapter });

    export type BasePrismaClient = typeof prismaClient;
    ```

3.  **Configure the Module**

    Configure the `PrismaModule` in your `AppModule` imports and import `prismaClient` from `prisma-client.ts`.

    ```typescript
    // src/app.module.ts
    import { Module } from '@nestjs/common';
    import { PrismaModule } from 'nestjs-prisma';
    import { prismaClient } from './prisma-client';

    @Module({
      imports: [
        // you can register multiple Prisma Clients with unique names
        PrismaModule.forRootAsync({
          isGlobal: true,
          name: 'PrismaService', // 👈 must be unique for each PrismaClient
          useFactory: () => {
            return prismaClient;
          },
        }),
      ],
    })
    export class AppModule {}
    ```

4.  **Usage**

    Inject `PrismaService` providing the `BasePrismaClient` type from step 2.

    ```typescript "this.prisma.client"
    // src/app.service.ts
    import { Inject, Injectable } from '@nestjs/common';
    import { PrismaService } from 'nestjs-prisma';
    import type { BasePrismaClient } from './prisma-client';

    @Injectable()
    export class AppService {
      constructor(
        @Inject('PrismaService') // 👈 use unique name to reference
        // Use `BasePrismaClient` for correct type-safety
        private prisma: PrismaService<BasePrismaClient>,
      ) {}

      users() {
        // access prisma.client.* for your queries
        return this.prisma.client.user.findMany();
      }
    }
    ```

</Steps>
